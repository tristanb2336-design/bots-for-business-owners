# Bots for Business Owners

A free, sourced directory of real ways non-technical small business owners use AI agents.

Live: https://bots-for-business-owners.vercel.app

Stack: Astro (static). Content lives in `src/data/usecases.mjs`. Every entry must cite a public source; never invent businesses, quotes or numbers.

```
npm install && npm run build
```
